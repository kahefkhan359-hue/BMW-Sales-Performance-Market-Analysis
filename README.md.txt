# BMW Sales Performance & Market Analysis
### Data Analytics Project | 2010–2024

## 1. Project Overview

The BMW Sales Performance & Market Analysis project focuses on analyzing BMW vehicle sales data from 2010 to 2024 to explore sales performance, model comparisons, regional distribution, and vehicle attributes.

This project combines SQL-based data analysis with interactive Tableau dashboards to transform raw data into meaningful business insights and visual reports.

The objective is to demonstrate practical skills in SQL, data analysis, KPI development, data visualization, and business intelligence reporting.

## 2. Business Objectives

The primary objectives of this project are:

- Sales Performance Analysis: Analyze available sales metrics and explore their distribution across the analysis period.
- Model Performance Analysis: Compare BMW models using available sales and vehicle-related metrics.
- Regional Analysis: Investigate sales distribution and differences across geographic regions.
- Vehicle Attribute Analysis: Explore characteristics such as fuel type, transmission, vehicle color, engine size, mileage, and price.
- Interactive Reporting: Develop Tableau dashboards that support data exploration through visualizations and filters.
- Data-Driven Insights: Identify meaningful patterns that may support further business investigation.

## 3. Dataset Overview

The project uses a CSV dataset containing BMW vehicle and sales-related information for the period 2010–2024.

Dataset Details:

- Data Domain: Automotive Sales Analytics

Key Attributes:

Note: The analysis is based on the fields and records available in the supplied dataset. Results should not be interpreted as officially audited BMW sales figures unless the dataset source and methodology establish that.

The project includes a Home page and four analytical dashboards.

### Dashboard 1: Executive Overview

Provides a consolidated overview of key sales and performance metrics. It helps users review the available dataset at a high level.

Focuses on comparing BMW models using the available sales and vehicle-related metrics. It helps users explore differences between models and identify leading performers according to the selected measures.

### Dashboard 3: Regional Analysis

Examines regional sales distribution and performance. It allows users to compare geographic regions and explore differences in the available sales metrics.

### Dashboard 4: Vehicle and Attribute Analysis

Explores vehicle characteristics such as fuel type, transmission, color, mileage, engine size, and price, depending on the fields available in the dataset.

## 8. Analytical Approach
